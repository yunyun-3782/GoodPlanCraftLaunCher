Features

核心功能

为玩家打造的实用工具

🔑

正版登录

支持 Microsoft 账户正版登录，安全验证，合规使用。

📦

版本自动管理

一键下载、安装、切换 Minecraft 各版本，自动处理依赖库与资源文件。

🚀

极速启动

优化的启动流程与缓存机制，点击即玩，告别漫长等待。

☕

Java 运行时管理

自动检测并补全 Java 运行环境，支持自定义镜像源地址（默认使用清华大学开源镜像站）。

🎨

视觉主题适配

完整支持浅色模式与深色模式，自动跟随系统外观偏好设置，提供一致的视觉体验。

🔄

自动更新与维护

内置更新检测机制，支持日志自动清理策略（清理周期可配置），保持启动器长期整洁高效。

System

系统要求

🔧 配置需求

操作系统：Windows 10 64位（1709+），Windows 11 同样兼容
Java：启动器自动补全，但建议手动清理系统中冗余或冲突的 Java 文件
存储：启动器本体至少 90MB 可用空间（不含游戏本体）
内存：建议 2 GB 以上可用内存
